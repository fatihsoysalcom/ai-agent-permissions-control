# AI Agent Permissions Control

This Python example demonstrates the risks of an AI agent having more permissions than a user and how to mitigate this using the principle of least privilege. It simulates user and agent permissions and shows how to restrict the agent's access to only what is necessary and permissible.

## Language

`python`

## How to Run

Save the code as `ai_agent_permissions.py` and run it from your terminal using: `python ai_agent_permissions.py`
